# 세기말일보 1993–2025

1993년부터 2025년까지 대한민국의 해마다 가장 중요했던 뉴스 10개씩, 모두 330건을 신문 1면 형식으로 정리한 HTML 리포트입니다.

## 보는 법

`index.html`을 브라우저로 열면 됩니다. 별도 빌드나 서버가 필요 없습니다.

- 연도마다 신문 1면 한 장(제1호~제33호)
- 머리기사(1위) + 2~10위 기사 9건
- 상단 연도 목록으로 원하는 해로 이동
- 라이트/다크 모드, 모바일 화면 지원

## 참고

- 제호 「세기말일보」는 가상의 이름입니다.
- 순위는 사회적 파장과 이후 역사에 미친 영향을 기준으로 정리했으며 주관이 들어가 있습니다.
- 내용은 원자료와 대조 검증을 거치지 않았습니다. 인용이나 수치를 쓰실 때는 원문을 확인해 주세요. 원문을 줄인 발언에는 "(요지)"를 붙였습니다.
